    Como os números foram contados

    • Cenários: blocos Scenario/Cenário nos arquivos Gherkin, testes it() do Cypress e casos de teste do Robot Framework nas pastas tests/. Features auxiliares do Karate marcadas com @ignore não entram.
    • Testes escritos, não execuções: o painel mostra o que existe no código. Ele não mostra taxa de sucesso.
    • CI configurado não é CI verde: no Ruby E2E Framework o pipeline está pausado (só disparo manual), a suíte do Karate API Framework ainda não teve a primeira execução completa, e o workflow do BDD GenerationX cuida de versionamento.
    • Evolução no tempo: para cada commit de cada repositório, os testes foram recontados naquela versão do código; o gráfico soma o último valor de cada projeto ao fim de cada trimestre. Commits são contados pela data do histórico completo.
