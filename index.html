DataSeed

Geração e seed de dados para testes

Abrir aplicação Ver código

Problema

Dados de teste instáveis e inconsistentes deixavam os cenários frágeis e dependentes do estado de cada ambiente.

Solução

Aplicação web que centraliza a criação e o seed de dados de teste, com interface de gestão e integração com automações e APIs.

Resultado

Testes menos dependentes de dados instáveis e mais confiáveis. Aplicação publicada e em uso.

QA Playground

Plataforma em português para praticar QA

Abrir aplicação Ver código

Problema

Quem estuda QA encontra aplicações de demonstração instáveis ou irreais, e projetos reais complexos demais para começar.

Solução

Ambiente estável com desafios por nível (júnior, pleno e sênior) para testes manuais, automação Web, Mobile, APIs e BDD. Feito com TypeScript, SCSS e API mockada.

Resultado

Plataforma gratuita e open source, disponível para qualquer pessoa praticar QA em português.
